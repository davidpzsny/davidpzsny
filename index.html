01

The website

Live countdowns, a schedule of every badge event, a page for each badge, search, light and dark themes, and a phone layout with its own navigation.

02

The bot

A Python bot on GitHub Actions checks Twitch every 15 minutes, updates the data and rebuilds every page, so the site never needs a manual deploy.

03

X bot

@BadgeDatabase on X is run by a bot: every new badge is posted with a generated image, and badge events get "now available" and "ending soon" posts. Events are also synced to Discord.

04

Reminders

Visitors can ask for a browser notification when dates are announced, when a badge starts and before it ends, sent by my own push server.

05

24/7 Twitch stream

A round-the-clock stream on twitch.tv/badge_db with 1,800+ followers, showing an overlay I built: live countdowns and the badges you can earn in the current category, updated without a restart.

06

Insights

Badge popularity, statistics by month and year, and the most watched categories with the badges you can earn in each.
